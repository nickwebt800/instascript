Supported subtitle formats

This subtitle converter reads one VTT, SRT or SBV source at a time. It accepts local files and pasted text, then writes standard SRT or WebVTT. Cue order, time ranges, line breaks and subtitle text are kept while format-specific headers and separators are normalized.

Use it as an SRT to VTT, SRT to WebVTT or subtitle converter when you need a browser-local format change. It writes an SRT file generator result from the cues you review; it does not invent speech or timing.

SBV input uses the comma-separated time-range form commonly found in SubViewer files. This page does not transcribe audio, merge files, store projects, require a login, or send subtitle text to a server.

How conversion works

The browser reads each cue's start time, end time and text. SRT output receives numbered cues and comma milliseconds. VTT output receives a WEBVTT header and period milliseconds. Existing cue times are not recalculated or rounded beyond the format's three-digit millisecond field.

If a source has a cue that does not match the selected subtitle syntax, it is not silently invented. The page reports that it could not find usable cues so you can correct the pasted text.

FAQ

Can I convert VTT to SRT without uploading the file?

Yes. Paste the VTT text or open one local VTT file. Reading and conversion happen in this browser.

Can I convert SRT to VTT on this page?

Yes. Open or paste SRT, choose VTT under Output format, then copy or download the WebVTT result.

Does it support SBV?

Yes. SBV is accepted as an input format. Choose SRT or VTT for the output.

Can I convert several files at once?

No. This page intentionally handles one subtitle file at a time so the workflow stays local and easy to review.
