Which kind of Instagram caption do you need?

A post description, spoken transcript and words printed on a video are different sources. Choose the one you actually need before starting a transcription.

1. Separate the three text sources

A post description is written beside the post. Spoken captions represent audible words. On-screen text belongs to the picture and can differ from both. InstaScript recognizes English speech; it does not scrape post descriptions or comments and does not perform OCR.

Check: Your requested text comes from speech, rather than text visible only in the post or picture.

Continue in the matching tool

2. Choose a public-link or local-file route

Use Instagram Transcript Generator for a supported public Instagram URL, or a permitted saved recording. Public media retrieval can fail for unavailable or restricted sources. The server retrieves Instagram media before browser recognition; local file processing stays on your device.

Check: A link that fails to fetch is not proof that the speaker said nothing.

Continue in the matching tool

3. Verify spoken words against the recording

Replay important phrases with the actual recording player and use timestamps to seek. There is no waveform view here. If you also record a post description in your notes, label it separately. Copy/TXT/Markdown use edited words; valid SRT/VTT cues can be checked in Subtitle Editor.

Check: Names, numbers and qualifiers match the audio, and other text sources remain separately labelled.

More questions and limits

What processing and privacy boundaries apply?

Local-file recognition and editing stay in the browser. Public Instagram URL retrieval uses the server and may use a fallback retrieval service before browser recognition. There is no saved transcript account history.

Where should I continue?

Open the matching tool and follow its current input requirements. Keep the original, review your result and download it before closing the tab.
