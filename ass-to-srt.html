What ASS to SRT conversion keeps

ASS and SSA files store timed dialogue inside an [Events] section. This converter reads each Dialogue: line, maps its start and end times to SRT's comma-millisecond format, and writes the dialogue text as a numbered SRT cue. It also turns ASS's \N line-break marker into a real line break.

ASS styling is presentation metadata, not spoken text. The conversion removes inline override tags such as {\an8} so the exported SRT contains readable captions. Cue timing, order, and text remain available for review in the result box.

Private, local workflow

Open one local file or paste its contents, then convert. Parsing happens in this browser; no subtitle text is uploaded, stored, or sent to a server. The page does not transcribe audio, render a video preview, merge files, or recreate ASS styling in SRT.

FAQ

Does it support SSA files?

Yes. SSA uses the same dialogue structure as ASS for the fields this converter needs. Open a .ssa file or paste its text.

What if the file has a custom Events format?

The parser reads the Format: line in [Events] and finds the Start, End and Text columns. If there is no usable dialogue format, it reports the problem instead of guessing.

Are fonts, colors and positioning preserved?

No. SRT has no equivalent for ASS styles and positioning. Inline style tags are stripped while the caption words and timing are retained.

Can I edit the converted captions?

Yes. Review or correct the SRT in the result box, then copy or download it. For cue-by-cue timing edits, open the result in the Subtitle Editor.
