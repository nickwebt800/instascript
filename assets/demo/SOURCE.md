# Prepared transcript sample

The homepage uses an 11-second excerpt of John F. Kennedy's inaugural address,
delivered on January 20, 1961. It is a prepared editing/export demonstration,
not a live transcription, recognition-quality test or speed benchmark.

- Recording: John F. Kennedy, 1961 inaugural address.
- Original archive: John F. Kennedy Presidential Library and Museum; see the
  [National Archives transcript](https://www.archives.gov/milestone-documents/president-john-f-kennedys-inaugural-address).
- Recording rights: the [Wikimedia Commons recording record](https://commons.wikimedia.org/wiki/File:JFK_inaugural_address.ogg)
  identifies the federal-government recording as public domain and applies the
  [Public Domain Mark 1.0](https://creativecommons.org/publicdomain/mark/1.0/).
  No endorsement by Kennedy, the archive or Wikimedia is implied.
- Excerpt file obtained from the [Transformers.js documentation sample](https://huggingface.co/datasets/Xenova/transformers.js-docs/resolve/main/jfk.wav)
  on October 15, 2026. The downloaded excerpt is redistributed unchanged.
- Local file: `kennedy-1961.wav`, stereo PCM16, 44,100 Hz, 485,100 frames,
  11 seconds.
- SHA256: `aa81c2552465568567e670f3823117e633900d16bd6202346a72f3c8464c74c8`.
- `kennedy-1961.json` contains prepared text based on the archived speech,
  with editorial punctuation and draft phrase timings. These timings are
  provided only for trying playback and subtitle exports; they are not a
  forced-alignment result. Visitor edits do not change the bundled source.

The browser requests this public sample only after **Try a sample**. Copy,
editing and downloads run locally. No speech model or external transcription
service is invoked by the demonstration.
