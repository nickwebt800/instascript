What a subtitle translator does here

Open an existing SRT or VTT file, read each source cue, and type the translated wording beside it. The editor keeps the original start and end times, so the downloaded SRT stays aligned with the recording. This is useful when you already have a transcript and need a reviewable subtitle translation.

The page does not listen to audio, identify speech, or send text to a translation API. It also does not guarantee that a literal translation fits a viewer's reading speed. Review names, numbers, line breaks, punctuation, and cue length in the target language before publishing.

FAQ

Does it translate automatically?

No. It is a local cue editor. You supply or paste the translation, which keeps the text private and makes each wording change reviewable.

Can I translate an SRT to another language?

Yes. Open the SRT, enter the target-language cue text, and download a new SRT with the original timing.

Can I use a VTT file?

Yes. VTT timing and cue text are read locally, then exported as SRT. VTT timecodes are converted to SRT HH:MM:SS,mmm format. VTT positioning settings, style blocks and cue tags are not retained. Invalid timecodes, end times at or before the start, and empty cues must be corrected before export. Valid overlapping cues keep their original timing.

Does it translate the spoken audio?

No. For speech recognition first, use the Instagram Transcript tool, then review the generated subtitle cues here.

Use subtitle text under 2 million characters and up to 10,000 cues. Invalid timing and empty source cues must be corrected before opening the file.
