What this subtitle editor does

A subtitle editor lets you open an existing subtitle file, change the text and timing of each cue, add or remove entries, and export the result. This page reads one SRT, VTT or SBV file at a time, parses it into individual cues, and shows them in an editable table where you can fix start times, end times and caption text before exporting.

Each cue becomes one row. Change the start or end time and the new value takes effect immediately. Edit the caption text to fix typos, rephrase, or trim a line. Add a new entry with the Add entry button, or remove one with its Remove button. The Shift all times field adds or subtracts a number of seconds from every timecode at once, which is the fastest way to fix a subtitle file that is uniformly early or late.

Everything runs in your browser. No subtitle text is uploaded, no account is required, and nothing is stored after you leave the page.

Supported formats

This subtitle editor reads SRT (numbered cues with comma-separated milliseconds), WebVTT (WEBVTT header with period-separated milliseconds), and SBV (comma-separated time ranges). Output is standard SRT or WebVTT. Cue order, time ranges, line breaks and subtitle text are preserved during editing.

The editor handles one local file at a time. It does not transcribe audio, merge multiple files, store projects, require a login, or send subtitle text to a server.

How editing works

When you load a subtitle file, each cue is split into a start time, an end time and its caption text. These appear as editable fields in the table. Timecodes use the HH:MM:SS,mmm format for SRT and HH:MM:SS.mmm for VTT. You can type times in any common shorthand such as 1:23.4 or 00:01:23,400 and the editor reads the numbers.

Shifting all timecodes is arithmetic: the editor adds your shift value (in seconds) to every start and end time. Negative values move subtitles earlier. Times below zero are clamped to zero so the cue does not get a negative start.

If a source has a cue that does not match SRT, VTT or SBV syntax, the editor reports that no usable cues were found so you can correct the pasted text.

FAQ

Can I edit SRT files without uploading them?

Yes. Open one local SRT file or paste its text. Parsing and editing happen in this browser only.

Can I edit VTT files here too?

Yes. Paste or open a VTT file. The WEBVTT header and period-separated milliseconds are handled automatically.

Does this subtitle editor support SBV?

Yes. SBV input with comma-separated time ranges is accepted. Export as SRT or VTT.

Can I shift all subtitle times at once?

Yes. Enter a number of seconds in the Shift all times field and click Apply shift. Use a negative number to move subtitles earlier.

Can I edit several subtitle files at once?

No. This page intentionally handles one subtitle file at a time so the workflow stays local and easy to review.

Does this editor show a video preview?

No. This editor works on the subtitle text and timecodes only. It does not play a video or show an audio waveform. If you need to check the result against the video, export the SRT or VTT and open it in your media player.

How do I get subtitles to edit?

If you have a video or audio file and need text first, use the Instagram Transcript tool or Video to Text to get an SRT. Then open that SRT here to edit timing and captions. If you have plain text and want to build subtitles from scratch, use the TXT to SRT Converter.
