## Gap order for daily pages

1. **Reproducible Reel transcript workflow:** public URL versus saved file, with failure cases.
2. **Transcript artifact details:** timestamps, TXT, SRT, and a copyable example.
3. **Privacy and processing boundary:** what stays in the browser and what the URL fetch does.
4. **Measured performance:** first-run model download versus cached inference.
5. **Verification guidance:** noisy music, overlapping voices, accents, and non-English speech.

The first daily page uses gap 1 plus gaps 2-4. It targets the first unused word-pool item: `instagram transcript generator`.
