What this TXT to SRT converter supports

Paste plain text or open a local .txt file to create subtitle cues. You can also open an existing .srt or .vtt file, switch to existing timestamps mode, edit every cue, and export either format. Only one local text file is handled at a time.

The converter does not send text to a server. It needs no account, login, history, project storage, paid API, or batch upload.

How timing works

In plain text mode, each line or sentence becomes a cue. The first cue starts at your chosen start time. Its duration uses the default duration and the reading-speed limit, then stays inside your shortest and longest duration settings. The next cue starts after the previous cue plus the entry gap.

Captions longer than the character limit are split at word boundaries. Existing SRT and VTT ranges are read as-is and rewritten with millisecond precision. If a source cue has no usable end time, the plain-text timing settings provide its fallback duration.

FAQ

Can I convert a TXT file to SRT without uploading it?

Yes. Choose Open TXT / SRT / VTT. The file is read locally by your browser and is not uploaded.

Can I use this as a TXT to SRT converter for numbered text?

Yes. Plain text mode removes common leading line numbers such as “1.” or “2)” before it creates cues.

What is the difference between SRT and VTT?

SRT uses comma-separated milliseconds and numbered cues. VTT starts with WEBVTT and uses a period before milliseconds. The editor can download both from the same entries.

Does this make subtitles from audio?

No. This page times text you provide. Use the Audio to Text tool when you need a transcript first.
