## 2. There's An AI For That (TAAFT)

**URL:** https://theresanaiforthat.com/submit/
**Cost:** Free
**Link type:** Nofollow
**DR:** ~72

**Tool name:** InstaScript
**Tagline:** Turn Instagram Reels & Videos into Text
**Category:** Video, Transcription, or Social Media
**Description (150 words):**
InstaScript is a free tool that converts Instagram Reels and videos into text transcripts. It runs OpenAI's Whisper speech recognition model entirely in the browser using transformers.js — no audio is uploaded to any server, no account is required, and no payment is needed. Users can either upload a video/audio file directly or paste a public Instagram URL to get the transcript. Output includes timestamped segments, and can be copied to clipboard or downloaded as TXT or SRT subtitle files. The tool uses the whisper-tiny.en model (~40 MB), which is cached by the browser after first load. It works on both desktop and mobile browsers.

## 4. SaaSHub

**URL:** https://www.saashub.com/submit
**Cost:** Free
**Link type:** Dofollow
**DR:** ~68

**Tool name:** InstaScript
**URL:** https://instascript.app
**Category:** Transcription Software, or Video Editing
**Description (enterprise-focused):**
InstaScript is a privacy-first transcription tool that processes audio and video entirely in the browser. Unlike server-based transcription services, no audio data ever leaves the user's device when using the file upload feature. The tool leverages OpenAI's Whisper model via Hugging Face's transformers.js library for in-browser AI inference. It supports Instagram URL input via server-side content fetching (Cloudflare Functions), file upload (MP4, WebM, MP3, WAV), and outputs timestamped transcripts in TXT and SRT formats. No registration, no API keys, no usage limits.
