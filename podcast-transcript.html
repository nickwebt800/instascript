Podcast transcript: the direct answer

A podcast transcript is spoken audio written as searchable text. Choose a local episode file above, press Transcribe this file, then review the timestamped result before copying TXT or downloading SRT. The page does not create text from a title or show notes.

How to transcribe an episode

  1. Choose one MP3, WAV, M4A or OGG file up to 100 MB.
  2. Let the browser load the speech model; the first run includes that download.
  3. Check names, numbers and speaker changes, then export TXT or SRT.

Spotify podcast transcript and Riverside FM transcript boundaries

A hosted Spotify or Riverside FM link is not fetched here. This page does not bypass logins or private projects. Use an audio file you have permission to process and keep the export with the source episode.

Privacy and review limits

The selected file is decoded and transcribed in the browser. There is no account, transcript history or server upload for this local-file workflow. Music, laughter, crosstalk, echo, clipping and unfamiliar accents can change words or timestamps. The model is intended for English speech and does not translate or label speakers.

FAQ

Can I paste a Spotify or Riverside link?

No. Save an audio file you are allowed to use and choose that file.

Does the audio leave my device?

No for the local-file workflow. The model runs in your browser and the page does not keep a server copy.

Can I use the result as captions?

Yes. Download SRT, then inspect cue breaks and names in your subtitle editor.
